# 果园分装

## 题目描述

果园里有 $n$ 堆果子，第 $i$ 堆有 $a_i$ 个果子。果农需要把所有果子合并成一堆。每次可以把**任意两堆**合并成一堆，消耗的体力等于两堆果子数量之和。

果农想知道，把所有果子合并成一堆，**最少**需要消耗多少体力。

## 输入格式

输入共两行。

第一行输入一个整数 $n$（$1\le n\le 10^5$）。

第二行输入 $n$ 个整数 $a_1, a_2, \dots, a_n$（$1\le a_i\le 10^9$）。

## 输出格式

输出一行一个整数，表示最少消耗的体力。

## 样例输入 1

```
3
1 2 9
```

## 样例输出 1

```
15
```

## 样例解释 1

先合并 $1$ 和 $2$，消耗 $3$，再与 $9$ 合并，消耗 $12$，总计 $15$。

## 样例输入 2

```
5
1 2 3 4 5
```

## 样例输出 2

```
33
```

## 数据范围

对于所有测试数据，保证：

- $1\le n\le 10^5$；
- 对于任意 $1\le i\le n$，$1\le a_i\le 10^9$。

| 测试点 | $n\le$ | 特殊性质 |
|---|---|---|
| $1,2$ | $10$ | 无 |
| $3\sim 5$ | $18$ | 无 |
| $6\sim 8$ | $10^2$ | A |
| $9\sim 11$ | $10^2$ | 无 |
| $12\sim 14$ | $5000$ | B |
| $15\sim 17$ | $5000$ | 无 |
| $18\sim 21$ | $10^5$ | A |
| $22\sim 25$ | $10^5$ | 无 |

特殊性质 A：对于任意 $1\le i\le n$，$a_1=a_2=\dots=a_n$。

特殊性质 B：$a_1, a_2, \dots, a_n$ 两两不同。

时间限制：1s；空间限制：512MB。
