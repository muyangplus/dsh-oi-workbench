# 果园分装 —— 验证记录

## 题卡

- 级别：入门组（入门级）
- 难度系数：贪心法【3】+ STL 容器 stack/queue/vector【4】（入门级上限【5】合规）
- 主知识点：贪心（Huffman 合并）+ STL 堆容器
- 超纲检查：全部知识点 ≤ 入门级【5】✓
- 正解复杂度：O(n log n)

## 测试点表格（与题面"数据范围"小节一致，灵活分档）

| 测试点 | $n\le$ | 特殊性质 |
|---|---|---|
| $1,2$ | $10$ | 无 |
| $3\sim 5$ | $18$ | 无 |
| $6\sim 8$ | $10^2$ | A |
| $9\sim 11$ | $10^2$ | 无 |
| $12\sim 14$ | $5000$ | B |
| $15\sim 17$ | $5000$ | 无 |
| $18\sim 21$ | $10^5$ | A |
| $22\sim 25$ | $10^5$ | 无 |

- 特殊性质 A：所有 $a_i$ 相等（生成器按单一值输出）
- 特殊性质 B：$a_i$ 两两不同（生成器用 `random.sample`）
- 共 25 个测试点 × 4 分 = 100 分；分档自由（8 档），非固定三档

## 样例

- 样例 1/2：题面内联（小样例，覆盖不同规模）
- 样例 3（大样例）：`large_sample/sample3.{in,ans}`（n=1e5 随机，满足 22~25 档约束），
  打包为 `additional_file/sample3.zip`，题面以 `[sample3.zip](file://sample3.zip)` 引用；
  **不进入评测数据**

## 数据构成（25 点，每档 = 边界/极限/定向击杀/随机）

- 边界：n=1、n=2（×2）
- 极限：n=1e5 随机/单调/交替/大值
- 定向击杀（int 溢出）：#16 #19 #21 #23 #25
- 特殊性质档：A 档 6 点（全相等，含 1e9 大值击杀）、B 档 3 点（两两不同）

## 击杀矩阵（实测，Windows g++ 14.2, O2）

| 程序 | 类型 | 预期 | 实测 |
|---|---|---|---|
| std.cpp（堆） | 正解 | 25/25 AC，最坏 ≤ TL/3 | 25/25 AC；#22 = 214ms（TL=1000ms）✓ |
| brute.cpp（每轮排序） | 暴力 | 1-5 AC | 1-5 全 AC ✓ |
| wrong_scan.cpp（O(n²) 扫描） | 复杂度层错解 | 1-17 AC（68 分），18-25 TLE | 1-17 全 AC ✓；#22 = 14.1s → TLE ✓ |
| wrong_int.cpp（int 累加） | 实现层错解 | 大答案点 WA，小数据 AC | #16/#19/#21/#23/#25 WA ✓；1-5 全 AC ✓ |

## 对拍与复现

- std vs brute：1-5 全部一致；生成器固定 seed，25 点全量可复现
- 生成器 `generator/gen_fruit.py` 按档位参数生成，特殊性质可精确制造

## 打包

  problem.yaml + problem.md + testdata/（config.yaml 25 cases 等分 + 数据）
