# 三角形计数（triangle）

## 题目描述

小 K 有 $n$ 根木棍，第 $i$ 根木棍的长度为 $a_i$。

小 K 想从中选出 **恰好 3 根**木棍，使得它们首尾相接能够组成一个**面积大于 0 的三角形**。

请你帮助小 K 计算有多少种不同的选择方案。两种方案不同当且仅当选择的木棍下标集合不同。

## 输入格式

从文件 `triangle.in` 中读入数据。

输入的第一行包含一个正整数 $n$。

输入的第二行包含 $n$ 个正整数 $a_1, a_2, \dots, a_n$。

## 输出格式

输出到文件 `triangle.out` 中。

输出一行一个整数，表示能组成三角形的方案数。

## 样例输入 1

```text
5
1 2 3 4 5
```

## 样例输出 1

```text
3
```

## 样例输入 2

```text
4
2 2 3 4
```

## 样例输出 2

```text
3
```

## 数据范围

对于所有测试数据，保证：

- $1 \le n \le 5000$；
- $1 \le a_i \le 10^9$。

| 测试点编号 | $n \le$ | $a_i \le$ | 特殊性质 |
|---|---|---|---|
| $1,2$ | $10$ | $10^3$ | 无 |
| $3,4$ | $100$ | $10^3$ | A |
| $5 \sim 7$ | $500$ | $10^6$ | 无 |
| $8 \sim 10$ | $500$ | $10^9$ | A |
| $11 \sim 14$ | $2000$ | $10^6$ | B |
| $15 \sim 18$ | $5000$ | $10^9$ | 无 |
| $19,20$ | $5000$ | $10^9$ | A |

特殊性质 A：所有 $a_i$ 互不相同。

特殊性质 B：$a_i$ 已经按非降序给出。

时间限制：1s；空间限制：512MB。
