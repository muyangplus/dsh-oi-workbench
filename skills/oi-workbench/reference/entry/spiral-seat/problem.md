# 螺旋座位（spiral）

## 题目描述

某考场有 $n$ 行 $m$ 列座位。老师按**从外到内、顺时针螺旋**的顺序给座位编号：

- 从第 $1$ 行第 $1$ 列开始；
- 先沿第 $1$ 行向右，再沿最后一列向下，再沿最后一行向左，再沿第 $1$ 列向上；
- 每走完一圈后进入更内层的矩形继续编号，直到所有 $n \times m$ 个座位都被编号。

编号从 $1$ 到 $n \times m$。给定一个编号 $k$，请你输出它所在的**行号和列号**。

## 输入格式

从文件 `spiral.in` 中读入数据。

输入仅一行，包含三个正整数 $n, m, k$。

## 输出格式

输出到文件 `spiral.out` 中。

输出一行两个整数 $r, c$，表示编号 $k$ 的座位在第 $r$ 行第 $c$ 列。

## 样例输入 1

```text
3 4 5
```

## 样例输出 1

```text
2 4
```

## 样例输入 2

```text
4 4 13
```

## 样例输出 2

```text
2 2
```

## 数据范围

对于所有测试数据，保证：

- $1 \le n, m \le 10^9$；
- $1 \le k \le n \times m$。

| 测试点编号 | $n, m \le$ | 特殊性质 |
|---|---|---|
| $1,2$ | $10$ | 无 |
| $3,4$ | $100$ | A |
| $5 \sim 7$ | $10^3$ | 无 |
| $8 \sim 10$ | $10^5$ | A |
| $11 \sim 14$ | $10^9$ | B |
| $15 \sim 20$ | $10^9$ | 无 |

特殊性质 A：$n = m$。

特殊性质 B：$k$ 位于最外圈。

时间限制：1s；空间限制：512MB。
