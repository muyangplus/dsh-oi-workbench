# 数字串排序（sortnum）

## 题目描述

小 O 有 $n$ 个仅由数字字符组成的字符串 $s_1, s_2, \dots, s_n$，每个字符串都不含前导零。
小 O 想把这 $n$ 个字符串按某种顺序首尾拼接，得到一个尽量大的十进制整数。

例如，`["9", "91"]` 可以拼成 `991` 或 `919`，其中较大的是 `991`。

请你帮助小 O 求出能拼出的最大整数。

## 输入格式

从文件 `sortnum.in` 中读入数据。

输入的第一行包含一个正整数 $n$。

接下来 $n$ 行，每行包含一个字符串 $s_i$。

## 输出格式

输出到文件 `sortnum.out` 中。

输出一行一个整数，表示能拼出的最大整数。

## 样例输入 1

```text
2
9
91
```

## 样例输出 1

```text
991
```

## 样例输入 2

```text
4
12
121
1211
1
```

## 样例输出 2

```text
1212112111
```

## 样例解释 2

一种达到最大值的拼接顺序为：`1211`、`121`、`12`、`1`。

## 数据范围

对于所有测试数据，保证：

- $1 \le n \le 10^5$；
- $1 \le |s_i| \le 10$；
- $s_i$ 仅包含数字字符，且 $s_i[0] \neq \text{`0`}$；
- $\sum |s_i| \le 10^6$。

| 测试点编号 | $n \le$ | $\sum \lvert s_i\rvert \le$ | 特殊性质 |
|---|---|---|---|
| $1$ | $2$ | $20$ | 无 |
| $2,3$ | $10$ | $100$ | 无 |
| $4,5$ | $10^3$ | $10^4$ | A |
| $6 \sim 8$ | $10^3$ | $10^4$ | 无 |
| $9 \sim 12$ | $10^5$ | $10^5$ | A |
| $13 \sim 16$ | $10^5$ | $10^6$ | B |
| $17 \sim 20$ | $10^5$ | $10^6$ | 无 |

特殊性质 A：所有 $s_i$ 的长度都相等。

特殊性质 B：所有 $s_i$ 的长度都不超过 $3$。

时间限制：1s；空间限制：512MB。
