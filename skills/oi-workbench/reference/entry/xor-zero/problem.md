# 异或为零（xorzero）

## 题目描述

小 Z 有一个长度为 $n$ 的非负整数序列 $a_1, a_2, \dots, a_n$。

定义一个区间 $[l, r]$（$1 \le l \le r \le n$）的权值为
$a_l \oplus a_{l+1} \oplus \dots \oplus a_r$，其中 $\oplus$ 表示按位异或。

小 Z 想知道，有多少个区间的权值等于 $0$。

## 输入格式

从文件 `xorzero.in` 中读入数据。

输入的第一行包含一个正整数 $n$。

输入的第二行包含 $n$ 个非负整数 $a_1, a_2, \dots, a_n$。

## 输出格式

输出到文件 `xorzero.out` 中。

输出一行一个整数，表示权值为 $0$ 的区间数量。

## 样例输入 1

```text
4
1 2 3 0
```

## 样例输出 1

```text
3
```

## 样例输入 2

```text
5
0 0 1 1 0
```

## 样例输出 2

```text
10
```

## 数据范围

对于所有测试数据，保证：

- $1 \le n \le 5 \times 10^5$；
- $0 \le a_i < 2^{20}$。

| 测试点编号 | $n \le$ | 特殊性质 |
|---|---|---|
| $1$ | $10$ | 无 |
| $2,3$ | $100$ | A |
| $4,5$ | $100$ | 无 |
| $6 \sim 8$ | $10^3$ | A |
| $9 \sim 11$ | $10^3$ | 无 |
| $12 \sim 14$ | $10^5$ | B |
| $15 \sim 17$ | $10^5$ | 无 |
| $18 \sim 20$ | $5 \times 10^5$ | 无 |

特殊性质 A：所有 $a_i$ 均相等。

特殊性质 B：$a_i \in \{0, 1\}$。

时间限制：1s；空间限制：512MB。
