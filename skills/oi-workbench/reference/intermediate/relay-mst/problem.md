# 网络中继（relay）

## 题目描述

某国有 $n$ 座城市和 $m$ 条可修复的双向道路。第 $i$ 条道路连接 $u_i$ 和 $v_i$，修复费用为 $w_i$。

另外还有 $k$ 个可建设的中继站。建设第 $j$ 个中继站的费用为 $c_j$；建设后，可以在该中继站与任意一座城市之间单独修建一条“直达链路”，第 $j$ 个中继站与第 $i$ 座城市之间修建直达链路的费用为 $b_{j,i}$。

政府希望以最小总费用让所有 $n$ 座城市两两连通。城市之间可以通过修复的道路、中继站与直达链路互相到达。中继站可以不建设，也可以建设多个。

请你求出最小总费用。

## 输入格式

从文件 `relay.in` 中读入数据。

输入的第一行包含三个非负整数 $n, m, k$。

接下来 $m$ 行，每行三个非负整数 $u_i, v_i, w_i$。

接下来 $k$ 行，第 $j$ 行包含 $n+1$ 个非负整数 $c_j, b_{j,1}, b_{j,2}, \dots, b_{j,n}$。

## 输出格式

输出到文件 `relay.out` 中。

输出一行一个非负整数，表示最小总费用。

## 样例输入 1

```text
4 4 2
1 4 6
2 3 7
4 2 5
4 3 4
1 1 8 2 4
100 1 3 2 4
```

## 样例输出 1

```text
13
```

## 数据范围

对于所有测试数据，保证：

- $1 \le n \le 1000$，$1 \le m \le 5000$，$0 \le k \le 5$；
- $1 \le u_i, v_i \le n$，$u_i \ne v_i$；
- $0 \le w_i, c_j, b_{j,i} \le 10^9$；
- 原 $n$ 座城市通过原有道路两两可达。

| 测试点编号 | $n \le$ | $m \le$ | $k \le$ | 特殊性质 |
|---|---|---|---|---|
| $1 \sim 4$ | $50$ | $200$ | $0$ | 无 |
| $5,6$ | $100$ | $300$ | $5$ | A |
| $7,8$ | $200$ | $500$ | $5$ | 无 |
| $9,10$ | $500$ | $2000$ | $5$ | A |
| $11 \sim 14$ | $1000$ | $5000$ | $5$ | A |
| $15 \sim 18$ | $1000$ | $5000$ | $5$ | 无 |
| $19 \sim 25$ | $1000$ | $5000$ | $5$ | 无 |

特殊性质 A：所有 $c_j = 0$，且每个中继站至少存在一条费用为 $0$ 的直达链路。

时间限制：1s；空间限制：512MB。
