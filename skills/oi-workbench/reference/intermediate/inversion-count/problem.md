# 逆序对计数（inversion）

## 题目描述

对于一个 $1 \sim n$ 的排列 $p_1, p_2, \dots, p_n$，若存在 $i < j$ 且 $p_i > p_j$，则称 $(i, j)$ 是一个**逆序对**。

给定 $n$ 和 $k$，请你计算有多少个 $1 \sim n$ 的排列恰好有 $k$ 个逆序对。答案对 $998244353$ 取模。

## 输入格式

从文件 `inversion.in` 中读入数据。

输入仅一行，包含两个正整数 $n, k$。

## 输出格式

输出到文件 `inversion.out` 中。

输出一行一个整数，表示答案对 $998244353$ 取模后的值。

## 样例输入 1

```text
3 1
```

## 样例输出 1

```text
2
```

## 样例输入 2

```text
4 3
```

## 样例输出 2

```text
6
```

## 数据范围

对于所有测试数据，保证：

- $1 \le n \le 500$；
- $0 \le k \le \frac{n(n-1)}{2}$。

| 测试点编号 | $n \le$ | $k$ | 特殊性质 |
|---|---|---|---|
| $1,2$ | $10$ | $\le n(n-1)/2$ | 无 |
| $3 \sim 5$ | $50$ | $\le n(n-1)/2$ | A |
| $6 \sim 8$ | $100$ | $\le n(n-1)/2$ | 无 |
| $9 \sim 11$ | $200$ | $\le n(n-1)/2$ | B |
| $12 \sim 14$ | $300$ | $\le n(n-1)/2$ | 无 |
| $15 \sim 18$ | $500$ | $\le n(n-1)/2$ | A |
| $19 \sim 25$ | $500$ | $\le n(n-1)/2$ | 无 |

特殊性质 A：$k \le 10$。

特殊性质 B：$k \ge \frac{n(n-1)}{2} - 10$。

时间限制：1s；空间限制：512MB。
