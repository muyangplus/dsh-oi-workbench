# 括号序列计数（bracket）

## 题目描述

一个长度为 $2n$ 的括号序列由 $n$ 个左括号 `(` 和 $n$ 个右括号 `)` 组成。

称一个括号序列是**合法的**，当且仅当：

- 任意前缀中左括号数量都不少于右括号数量；
- 整个序列中左括号数量等于右括号数量。

定义括号序列的**深度**为任意前缀中“左括号数减右括号数”的最大值。

给定 $n$ 和 $d$，请你计算有多少个长度为 $2n$ 的合法括号序列，满足其深度不超过 $d$。
答案对 $998244353$ 取模。

## 输入格式

从文件 `bracket.in` 中读入数据。

输入仅一行，包含两个正整数 $n, d$。

## 输出格式

输出到文件 `bracket.out` 中。

输出一行一个整数，表示答案对 $998244353$ 取模后的值。

## 样例输入 1

```text
3 2
```

## 样例输出 1

```text
4
```

## 样例输入 2

```text
4 1
```

## 样例输出 2

```text
1
```

## 数据范围

对于所有测试数据，保证：

- $1 \le n \le 5000$；
- $1 \le d \le n$。

| 测试点编号 | $n \le$ | $d$ | 特殊性质 |
|---|---|---|---|
| $1,2$ | $10$ | $\le n$ | 无 |
| $3 \sim 5$ | $100$ | $\le n$ | A |
| $6 \sim 8$ | $100$ | $\le n$ | 无 |
| $9 \sim 11$ | $1000$ | $=1$ | B |
| $12 \sim 14$ | $1000$ | $\le n$ | A |
| $15 \sim 17$ | $5000$ | $\le n$ | B |
| $18 \sim 20$ | $5000$ | $\le n$ | 无 |

特殊性质 A：$d \le 10$。

特殊性质 B：$d = 1$。

时间限制：1s；空间限制：512MB。
