# 三组分配（assign）

## 题目描述

有 $n$ 个物品需要分到三个组 $A, B, C$ 中。第 $i$ 个物品放入三个组分别获得价值
$a_{i,1}, a_{i,2}, a_{i,3}$。

为了保持平衡，任意一个组中的物品数量都不能超过 $\lfloor n/2 \rfloor$。

请你计算所有满足数量限制的分配方案中，总价值的最大值。

## 输入格式

从文件 `assign.in` 中读入数据。

输入的第一行包含一个正整数 $n$。

接下来 $n$ 行，第 $i$ 行包含三个非负整数 $a_{i,1}, a_{i,2}, a_{i,3}$。

## 输出格式

输出到文件 `assign.out` 中。

输出一行一个非负整数，表示最大总价值。

## 样例输入 1

```text
4
4 2 1
3 2 4
5 3 4
3 5 1
```

## 样例输出 1

```text
18
```

## 样例输入 2

```text
2
10 9 8
4 0 0
```

## 样例输出 2

```text
13
```

## 数据范围

对于所有测试数据，保证：

- $2 \le n \le 100$，且 $n$ 为偶数；
- $0 \le a_{i,j} \le 2 \times 10^4$。

| 测试点编号 | $n \le$ | 特殊性质 |
|---|---|---|
| $1,2$ | $10$ | 无 |
| $3,4$ | $30$ | 无 |
| $5 \sim 7$ | $60$ | A |
| $8 \sim 10$ | $60$ | 无 |
| $11 \sim 13$ | $100$ | B |
| $14 \sim 16$ | $100$ | C |
| $17 \sim 20$ | $100$ | 无 |

特殊性质 A：$a_{i,2} = a_{i,3} = 0$。

特殊性质 B：$a_{i,3} = 0$。

特殊性质 C：所有 $a_{i,j}$ 均在 $[0, 2 \times 10^4]$ 中独立均匀随机生成。

时间限制：1s；空间限制：512MB。
