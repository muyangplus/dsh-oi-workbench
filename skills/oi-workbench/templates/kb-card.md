# 用户知识库速查卡片（模板）

> 把本模板复制到 `~/.dsh-oi-workbench/kb/<level-dir>/<topic>.md` 使用，
> 或按 `specs/user-content.md` 直接维护 `~/.dsh-oi-workbench/kb/` 下的卡片文件。
> 规范见 `specs/user-content.md`；层级目录映射：入门级→level-1-basic、
> 提高级→level-2-intermediate、专家级→level-3-expert、自定义层级→ASCII slug。

```markdown
---
topic: "并查集"
level: "提高级"
difficulty: 6
tags:
  - 并查集
  - 图论
  - 离线处理
summary: "维护动态连通分量：支持合并集合与查询两元素是否连通；可结合路径压缩与按秩合并做到近似常数。"
pitfalls: |
  - 路径压缩不改变树高的均摊上限，需配合按秩合并才稳定
  - 带权并查集注意向量方向的统一约定
  - 离线重排（如按边权排序）时务必确认询问与修改的先后关系
---

# 并查集（用户补充速查）

（可选正文：原理、复杂度、典型题型、变式、与本题工作台的结合点。）

## 复杂度与典型模型

- 均摊 O(α(n))
- 典型模型：连通性、最小生成树 Kruskal、在线/离线加边、带权/扩展域

## 典型题目 / 结合关卡

- （可选）给出想固化到题目中的剧情/约束灵感
```

## frontmatter 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `topic` | 是 | 知识点主题名（唯一；同名词条以用户卡为准） |
| `level` | 是 | 入门级 / 提高级 / 专家级，或用户自定义层级 |
| `summary` | 是 | 一句话概述：核心思想与适用场景 |
| `difficulty` | 否 | 难度系数 0–10（不超目标级别上限） |
| `tags` | 否 | 标签列表（检索用） |
| `pitfalls` | 否 | 易错点（`\|` 多行块） |

> 正文为可选详细讲解；技能「锁定知识点」时优先采用冒烟后确认的用户卡内容。
