# 变式卡片模板

> 母题卡与变式卡一体：先填母题卡，变式只动 1-2 个轴（见 `specs/variation-design.md`）。

## 母题卡

```markdown
# 母题卡：{{题目名}}
- 级别：入门级 / 提高级 / 专家级
- 知识依据：内部整理的知识点速查（见 knowledge-base/）
- 主知识点：{{如：区间 DP}}
- 辅助知识点：{{如：前缀和、位运算}}
- 超纲检查：{{结论，见 knowledge-base/workflow.md}}
- 母题复杂度：O(n³) → 满分优化 O(n²)
- 母题数据规模：n ≤ 300 / 5000
- 核心 idea（一句话）：{{合并相邻代价最小化}}
- 已有变式：{{空 | V1 描述 | ...}}
```

## 变式卡（每道变式一张）

```markdown
## 变式 {{编号}}：{{新题名}}

### 变式描述（一句话）
{{从母题改了什么}}

### 变式轴（勾选 1-2 个）
- [ ] 数据范围
- [ ] 限制条件
- [ ] 维度扩展
- [ ] 目标函数
- [ ] 结构特化
- [ ] 输出要求
- [ ] 知识点组合

### 知识点重锁定
- 级别：{{保持/升级}}
- 主知识点：{{可能变化}}
- 超纲检查：{{结论}}

### 分数表重设计（测试点分档/特殊性质）
| 档 | 测试点编号 | 约束 | 特殊性质 | 分值 |
|---|---|---|---|---|
| 20% | $1\sim 5$ | ... | 无 | 4 分/点 |
| 50% | $6\sim 12$ | ... | 无 | 4 分/点 |
| 100% | $13\sim 25$ | ... | 无 | 4 分/点 |

### 数据生成器改动
{{复用母题生成器改哪些参数 / 重写}}

### 错解枚举（新复杂度档位的典型错解）
| 错解 | 类型 | 击杀点 | 预期 |
|---|---|---|---|
| ... | ... | ... | ... |

### 验证记录
- [ ] std 全 AC
- [ ] 暴力对拍 ≥1 万轮
- [ ] 击杀矩阵全绿
- [ ] 题目包生成并校验
```

## 登记

变式完成后，把变式摘要登记回母题卡「已有变式」列表，防止撞车。
