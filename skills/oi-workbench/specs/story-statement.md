# 复杂背景故事题面与整卷交付规范

> 来源：CSP-S 模拟卷实战经验。目标：用大量背景故事/无效信息考察选手的读题与
> 关键信息提取能力，同时保证**题意不变、无歧义**。

## 1. 题面融入故事（**不设正式定义段**）

- **不单独写“正式定义段”**（2026-10-11 用户口径：“去除正式定义段，不允许选手偷懒”）：
  题面**只由故事承载题意**，不许出现“给定一个长度为 $n$ 的序列……请计算……”这类
  抽象复述段落；选手必须**读完故事**才能提取出要解决的问题，禁止跳读投机。
- **故事长度与质量**：
  - 目标 **300~500 字**（中文字符）；只有一句话的场景不算故事题面。
  - 必须具体：有**人物、地点、道具、事件推进**，读起来是一个连贯的小故事；
    可以塞入与解题无关的无效细节来增加读题量。
  - **禁止形式化口吻**（用户原话：“禁止出现形式化地，讲题面融入故事中”）：
    要把任务**融入故事**，由故事里的角色、道具、事件自然引出要解决的问题，
    包括：要算什么、输入里会给出什么、输出要输出什么形态。
- **信息完整性（无歧义是硬要求）**：虽然不设正式定义段，但题意必须**完整、精确、无歧义**：
  - 故事必须交代清楚：对象是什么、数据规模由故事中的场景自然体现、要输出什么；
  - 容易歧义的术语（子序列是否连续、端点是否包含、并列如何处理、空段是否允许等）
    放在 `## 说明与澄清` 里解释，仍只解释概念、不得提示做法或答案量级；
  - 「输入格式 / 输出格式 / 数据范围 / 样例」四节照旧保留，与题面故事不冲突；
    其中数据范围用表格给足约束，保证选手不会因为故事模糊而写错规模。
- **题意不变**：改写故事不得改动「输入格式 / 输出格式 / 数据范围 / 样例」的任何形式化内容。

## 2. 说明与澄清（只解释概念，禁止提示）

- 仅对**可能有歧义**的术语做解释，例如：
  - “子序列”是否要求连续；
  - “严格递增”中相等如何处理；
  - “连续子段”是否含空段；
  - 路径是否包含端点、$u_i=v_i$ 时经过几次；
  - 每个房间至少经过一次是否含入口/出口、是否允许重复走。
- **禁止提示性内容**，包括但不限于：
  - 答案量级/上限（如“最多可达 $\frac{n(n+1)}2$”）；
  - 请使用 64 位整数存储与输出（此说明可保留在“输出格式”作为规范，但不放入“说明与澄清”）；
  - “答案至少为 1”“只要求输出人数”“并列取编号最小”等已经由题意推出的结论；
  - 任何算法、复杂度、数据结构、边界实现提示。

## 3. 样例顺序

固定顺序（与官方试卷一致）：

```markdown
## 样例输入 1
## 样例输出 1
## 样例解释 1          # 紧跟样例 1 输出之后
## 样例输入 2
## 样例输出 2
## 样例 3              # 大样例，文件引用，不内联
```

## 4. 完整样例 zip（平铺格式）

- 每道题的完整样例压缩包为 `additional_file/<英文题名>_samples.zip`，**平铺**：
  `1.in / 1.out / 2.in / 2.out / 3.in / 3.out`
- **不要**使用“大样例/小样例”子目录，**不要**放 readme。
- 样例 1、2 = 题面内联的小样例；样例 3 = 大样例（默认取 `data/6`，满足测试点 6~8 约束）。

## 5. PDF 题面中的大样例引用格式

```markdown
## 样例 3

见选手目录下的 <英文题名>/<英文题名>3.in 与 <英文题名>/<英文题名>3.ans。
该样例满足测试点 6, 7, 8 的约束条件。
```

## 6. 整卷 PDF 组织方式（参考官方 CSP 试卷）

1. **封面页**：比赛名/副标题/级别/时间 + 信息表
   （题目名称/题目类型/目录/可执行文件名/输入文件名/输出文件名/
   每个测试点时限/内存限制/测试点数目/测试点是否等分）+ 提交源程序文件名 +
   编译选项 + 注意事项。
2. **每题分页**：页眉左为比赛名、右为“级别 + 题名（英文文件名）”，
   页脚为“第 X 页 共 Y 页”。
3. 小节固定：题目描述 / 输入格式 / 输出格式 / 样例（带行号）/ 样例解释 / 数据范围。
4. 样例使用带行号代码块；PDF 中不要出现链接红框（hyperref 用 `hidelinks`）。

```powershell
# 整卷 PDF（官方风格）
python generator/build_statement_pdf.py --contest "LKCP 非专业级软件能力认证" `
    --subtitle "2026 第二轮认证" --level "提高级" --time "2026 年 8 月 22 日 13:00~16:00" `
    --problems <题目录>... --story-dir <故事题面目录> --out paper.pdf

# Lemon 评测机比赛数据（含 std 选手与 <比赛>.cdf）
python generator/export_lemon.py --contest LKCP --problems <题目录>... --out dist/lemon
```
