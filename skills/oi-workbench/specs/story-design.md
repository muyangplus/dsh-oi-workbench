# 故事设计能力（story-card）

> 目标：为 OI 题面构造**大量背景故事 / 无效信息**，考察选手读题与提取关键信息的能力；
> 同时保证**题意不变、无歧义、零做法提示**。

## 1. 故事卡字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 题目名 / 主题 | 是 | 用于题面包装；主题可与知识点无关 |
| 世界观 | 是 | 一段话交代背景（组织/世界/年代） |
| 角色 | 是 | 2~5 个角色，含姓名、身份、与解题无关的特征 |
| 场景 | 是 | 事件发生的场所/器物 |
| 道具 / 无效信息 | 是 | 可大量堆叠数字、事件、物品，但不得与正式定义冲突 |
| 剧情主线 | 是 | 3~5 句，引出正式问题 |
| 知识点融入点 | 否 | 记录考点如何“隐入”剧情（**禁止**出现算法名/复杂度/提示） |
| 连续性标记 | 否 | 供连载/同场共享主线使用：涉及的角色/场景/道具/未解伏笔 |

## 2. 使用规则

- 故事段放在 `## 题目描述` 开头，可占多个自然段；之后必须紧跟**完整精确的正式定义段**。
- 无效信息只做“装饰”，不得替代定义；不得与输入格式/输出格式/数据范围冲突。
- 故事中**禁止**出现：算法名、数据结构名、复杂度、答案量级、64 位提示、
  “可 DP / 可二分 / 建议用堆”等任何做法提示。
- 若故事引入可能歧义的概念（如“连续子段”“子序列”），在【说明与澄清】中只做概念解释。

## 3. 生成器

`python generator/story_card.py`：

```powershell
python generator/story_card.py --title 登山选拔 --topic 最长上升子序列 `
    --knowledge 贪心 --knowledge 二分 --knowledge 动态规划 `
    --theme 雪山远征 --characters "队长:冷面王" "队员:铁腿阿强" `
    --scene 报名处 --props "旧口哨:1982年救过7人" "三碗牛肉面:纯属广告" `
    --output story.md
# --apply 直接插入到题目 problem.md 的「题目描述」开头
python generator/story_card.py --title 登山选拔 ... --apply drafts/csp-s-mock/climb/problem.md
```

生成结果 = 故事卡 + 一段可直接粘贴的背景故事（含大量无效信息，不泄露做法）。
