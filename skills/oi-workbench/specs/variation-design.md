# 变式生成规范

变式能力 = 从一道母题出发，系统化生成多道新题，且**知识点可控、难度可调、不重复**。这是 OI 题库建设的核心产能。

## 1. 母题卡（每道母题先填卡）

```markdown
# 母题卡：<题目名>
- 级别：入门级 / 提高级 / 专家级
- 主知识点：区间 DP
- 辅助知识点：前缀和、long long 溢出处理
- 母题复杂度：O(n³) → 满分优化 O(n²)
- 母题数据规模：n ≤ 300 / 5000
- 核心 idea（一句话）：合并相邻代价最小化
- 已有变式：无
```

## 2. 变式维度（七轴）

| 轴 | 操作 | 例子 |
|---|---|---|
| **数据范围** | 放大/缩小规模，改复杂度档位 | n≤10 → n≤2×10⁵，正解从暴力变 DP |
| **限制条件** | 加/删/改约束 | 加"ai 互不相同"、删"保证连通" |
| **维度扩展** | 一维→二维、单点→区间、单对象→多对象 | 单序列→环形；单串→双串匹配 |
| **目标函数** | 改最值/计数/方案/判定 | 求最小代价 → 求方案数 → 是否存在 |
| **结构特化** | 一般图→树/链/二分图；数组→矩阵 | 图上问题→树上问题 |
| **输出要求** | 只输出答案→输出方案→交互式 | 输出最小值 → 输出取法 |
| **知识点组合** | 与另一辅助知识点复合 | DP+字符串哈希；DP+矩阵快速幂 |

每次变式**只动 1-2 个轴**，防止变形过大失去与原题的联系（变式是训练价值，不是新原创题）。

## 3. 变式流程

1. 选定母题，填母题卡。
2. 选定 1-2 个变式轴，写出变式描述（一句话）。
3. 按 `knowledge-base/workflow.md` 重新锁定知识点：**变式后知识点必须仍在原级别范围内**；若变式把复杂度顶到超纲（如要求 O(n log n) 但该级别只有 O(n²) 知识点），则降级为"更高级别变式"或放弃。
4. 重写：题面（复用母题模板）、分数表（测试点分档/特殊性质随新复杂度台阶重设计）、数据生成器（复用母题生成器改参数）、std（改写）、错解（枚举新复杂度档位的典型错解）。
5. 击杀矩阵重做（数据设计随复杂度台阶变）。
6. 变式登记回母题卡（"已有变式"列表），防止重复生成。

## 4. 变式质量检查

- [ ] 只动 1-2 个轴，变式描述一句话能说清
- [ ] 新题知识点 ∈ 目标级别大纲
- [ ] 新题不能与原题"解题路径完全一致"（至少目标函数/结构/范围之一实质不同）
- [ ] 新题的分数表（测试点分档/特殊性质）按新复杂度台阶重设计（禁止照抄母题分数表）
- [ ] 新题数据生成器独立验证（std 全 AC、错解矩阵击杀）
- [ ] 与已有变式比较，避免撞车

## 5. 批量出题产能模型

一道母题按此流程可派生 3-6 道变式（每道 2-4 小时含数据验证）；配合本工作台 `skill/SKILL.md` 流水线，一个会话可一次交付"母题 + 2 道变式"的完整题目包。
