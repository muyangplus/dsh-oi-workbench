# v0.1.2 — 批次 2：标准 IO / 文件 IO 双模式 + 一般 OJ 评测模式

> 迭代号版本（dev 迭代期，不发布）。对应 `ROADMAP.md` 批次 2。

## Added

- `spec.json` 新字段（兼容旧字段）：
  - `io`：`{type: standard|file, input, output}` —— 标准 IO / 文件读写；兼容旧 `fileIO`；
  - `judge.mode`：`traditional` / `subtask` / `acm` —— 计分语义；缺省自动推断（`subtasks`→subtask，`type=acm`→acm）；
  - `judge.spj` + `judge.checker` / `judge.interactor` —— 特殊评测；兼容旧 `judge.type=special`。
- `generator/spec_support.py`：`io` / `judge` 归一化解析共享工具。
- `local_judge.py`：
  - 支持 `io.type=file`（运行时读/写 `io.input`/`io.output`，比对写出的文件）与 stdin/stdout；
  - 支持 spj：编译 `data/` 或 `checker/` 下 checker，按 testlib 约定（exit 0 = AC）评测；
  - 支持三种计分：traditional/acm 逐点、subtask 捆绑（组内全 AC 且依赖组通过才计分）；
  - 新增预热运行，消除新编译 exe 首次启动被本机杀软拖慢导致的假 TLE。

## Changed

- `build_package.py`（Hydro）：config.yaml 增加 `inputFile/outputFile`；spj 输出 `checker`；
  `data/` 下非 in/out 文件（checker/interactor 源码）一并写入 `testdata/`。
- `build_hoj_package.py`（HOJ）：`io` 映射 `isFileIO/ioReadFileName/ioWriteFileName`；
  `judge.mode` 驱动题型（acm→type=ACM）与 `judgeCaseMode`（subtask→subtask_lowest）；
  spj/checker 兼容（含 `judge.spjCode` 回退）。
- `verify_package.py` / `verify_hoj_package.py`：报告 file IO 与 spj 信息。
- `templates/problem.yaml`、`templates/statement.md`、`specs/statement-style.md`、`SKILL.md`：
  同步 `io` / `judge` 约定。

## Fixed

- Hydro 打包器原来不把 `data/` 下 checker/interactor 等非 in/out 文件写入 `testdata/`，
  导致 spj 包缺 checker（verify 报错）；已修复。

## 验证（本机冒烟）

- `local_judge`：p-file（io=file）100/100；p-subtask（捆绑+依赖）100/100（subtask1 +40、subtask2 +60）；
  p-spj 正解 100/100、错解 0/100（WA）；内置 `reference/entry/max-number` 回归 100/100。
- Hydro build+verify：p-file（config 含 inputFile/outputFile）、p-subtask、p-spj
  （config 含 checker 且 spj.cpp 进 testdata）、max-number 全绿。
- HOJ build+verify：p-file（isFileIO + read/write 名）、p-subtask（subtask_lowest）、
  p-spj（judge=spj）、max-number 全绿。
