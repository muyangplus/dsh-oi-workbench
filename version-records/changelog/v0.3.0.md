# v0.3.0 — DSH 0.2.1 适配：插件版本门禁、新宿主 API、原生「OI 工作台」面板

> 本次迭代解决两个问题：插件在 DSH 0.2.1-rc.2 上被版本门禁**整体跳过**（技能不注册、面板不加载），
> 以及遗留的「DSH 原生 UI 管理能力」未完成项。
> 迭代期只在 dev 仓库；发布时走 public `dev` → beta → PR `main` → 正式版 + tag `v0.3.0`。

## Added

- 原生「OI 工作台」面板：侧边栏 `sidebar.panellist` 入口行 + `main` 主面板，五个标签页
  总览 / 题目 / OJ / 比赛 / 帮助；题目扫描、检查、构建（Hydro / HOJ / 两者）、本地评测、
  打开目录，OJ 连接档案管理与连接测试，比赛计划保存与一键构建，命令输出与耗时回显。
- Host HTTP API：`GET /oi-workbench/api/state`、`GET /oi-workbench/api/problems`、
  `POST /oi-workbench/api/action`；wire 契约集中在 `src/api/contract.ts`，宿主与浏览器两侧共用。
- `oiwb_status` agent 工具：返回工作台根目录、题目数量、插件版本与 skill 注册状态。
- `scripts/verify_plugin.mjs`：不启动 GUI 的独立验收脚本，覆盖版本门禁、宿主 bundle 导入、
  skill provider、路由层、路径越界拦截、真实 `check`/`judge`、浏览器 bundle 模块表契约与发布文件集。
- `skills/oi-workbench/specs/native-panel.md`：原生面板的状态、动作、错误与安全边界规范。

## Changed

- `package.json`：版本升至 **0.3.0**；新增 `dsh.engines.dsh: ">=0.2.1-rc.2"` 版本门禁声明；
  `dsh.client.inject` 清空为基线模块（不再声明不存在的 `dsh-client-runtime` 行）；
  `peerDependencies` 改为 `@deepseek-ai/dsh` + `react`；开发依赖升级到 0.2.1-rc.2 一代。
- 宿主侧迁移到新 API：`@deepseek-ai/cordis`、`@deepseek-ai/schemastery`、
  `ctx.webServer.register(...)` / `ctx.tools.register(defineTool(...))` / `ctx.effect(...)`；
  Python 调用由同步 `execFileSync` 改为异步 `execFile`（不阻塞 Host）。
- Skill 注册方式：移除 `cordis.patch.yml` 中旧的 `dsh-skill-filesystem` 插入行，
  改由宿主插件 `ctx.skills.registerProvider()` 注册 `oi-workbench`（`resourceBase` 指向包内
  `skills/oi-workbench/`），每次读取正文，改文档即时生效。
- 浏览器侧迁移到 DSH 0.2.1 客户端插件模型：`apply(ctx)` + `ctx.slots.inject/register`，
  React 组件渲染，仅 `require` shell 基线模块（React / slots / store / primitives），
  不再内联第二份运行时。
- `tsconfig.json` / `tsdown.config.ts`：加入 `jsx: react-jsx`、DOM.Iterable，
  客户端入口改 `src/client/index.tsx`，externals 与 shell 的 `staticModules` 基线对齐。
- `README.md`：新增运行环境（DSH >= 0.2.1-rc.2）、原生面板能力、构建/验收命令，
  待办列表已勾掉「DSH 原生 UI 管理能力」并列出下一步。
- `skills/oi-workbench/SKILL.md`：新增原生面板与工具章节，明确安装与运行环境，
  删除过时的规划段与失效引用，压缩重复表述同时保留全部出题硬约束。

## Fixed

- 修复插件在 DSH 0.2.1-rc.2 上因 `peerDependencies: {"@deepseek-ai/dsh-tools": "^0.0.1-rc.1"}`
  不满足而被启动器跳过的问题（技能不出现、面板不加载）。
- 修复旧客户端入口引用已不存在的 `@deepseek-ai/dsh-client-ui-slots` 旧版 DOM `component().render`
  API 的问题。
- 修复旧宿主代码把 Python 工具路径写死为 `<工作台根目录>/skills/...` 的问题：
  现在按插件包自身位置解析 `skills/`，npm 安装目录与工作台根目录解耦。
- 修复旧面板接口无路径校验的问题：所有题目路径先 `realpath` 校验必须位于工作台根目录内。

## Security

- 面板与持久化配置**不保存明文密码/Token**：OJ 档案只存凭据的**环境变量名**（`credentialEnv`）。
- 所有命令式动作限制在工作台根目录内；批量构建保持 `--dry-run` 预演约定。
- 浏览器 bundle 仅从 DSH shell 基线模块取依赖，不引入第三方运行时。
