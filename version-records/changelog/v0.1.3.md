# v0.1.3 — 工程批次：HOJ 导出修复、盲审工具、评测规范清理、可选依赖化

> 迭代号版本（dev 迭代期，不发布）。非路线图内容批次（0.1.3 被本工程批次占用，
> 路线图批次 3–5 顺延至 0.1.4–0.1.6，见 `VERSION.md` / `ROADMAP.md`）。

## Fixed

- HOJ 打包导出与官方格式对齐：`problem_<pid>.json` 去掉 `_meta`，补齐
  `judgeMode/languages/samples/tags/problem/codeTemplates` 顶层键；
  `problem` 增加 `isGroup:false`、`isUploadCase:true`，并把 `## 数据范围` 自动写入 `hint`；
- HOJ 导出新增 `problem_<pid>/info`（mode/judgeCaseMode/version/testCasesSize/testCases，
  每点含 outputMd5/outputSize/allStrippedOutputMd5/EOFStrippedOutputMd5）；
  `verify_hoj_package.py` 同步校验 info↔samples 一致、outputMd5、OI 总分 100、关键字段齐全。

## Added

- 盲审工具 `generator/blind_review.py`，两道闸口：
  - 代码发布前 `--release`（扫仓库用户面向文本）；
  - 生成题目文件后 `--problem <题目目录>`（审题面/题解/spec）；
  - 检查项：无上下文内部语境泄漏（括号批次注解、版本号内部措辞、按路线图分批推进等）、
    题目内部术语泄漏（spec.json/生成器/对拍等）、占位残留（未完成的占位标记）、
    硬件规格泄漏（CPU 型号/主频/内存/睿频/能效核等）、无上下文时间注解（“（…后固定）”等）、
    编码/行尾空白/异常重复标点/未完句；发现问题退出码 1。

## Changed

- 清理无上下文内部表述：README / 知识库工作流去掉“（批次 1）”“版本约定 / ROADMAP 分批填充”等；
- SKILL.md「评测规范」小节去除硬件配置表达（原“评测机基准：Intel Core Ultra 9 … 内存 96 GB”），
  标题改为 `# 0. 评测规范`；`templates/statement.md`、`specs/statement-style.md` 同步去硬件；
- 去除对 `@etby-studio/dsh-commands` 的**强制依赖**：`dependencies` → 可选
  `peerDependencies`（`optional: true`）；`cordis.patch.yml` 的 `dsh-commands` 条目改为
  `disabled` 用 JS 表达式条件启用（装了才注册斜杠命令，未装自动跳过，不阻断插件装载）；
  README 将斜杠命令说明为可选项并给出安装方式。
