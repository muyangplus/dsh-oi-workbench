# v0.1.4 — 功能批次 3–5 聚合：故事能力 / 一键比赛 / 连载 / spj·交互 / testlib + 发布名变更

> 迭代号版本（dev 迭代期，本地发布构建）。将路线图批次 3/4/5 及多项工程能力聚合到 0.1.4，
> 并把 npm 包名调整为 `@muyangplus/dsh-oi-workbench`。

## Added

- 故事设计能力 `story-card`：`specs/story-design.md` + `templates/story-card.md` +
  `generator/story_card.py`（生成故事卡与背景故事段，支持 `--apply` 插入题面）。
- 一键出整场比赛 `generator/build_contest.py`：完整样例 zip + 整卷 PDF + Lemon（含 `.cdf`）
  + 每题 Hydro/HOJ 包。
- 连续剧情 / 连载：`specs/story-serial.md` + `templates/story.yaml` +
  `generator/story_continuity.py`（登场顺序 / 伏笔闭环 / 跨场引用检查）。
- 本地评测支持 **testlib checker** 与 **交互题 interactor**：`local_judge.py` 双向管道真机评测
  （interactor 退出码 0=AC），并内置 `generator/testlib/testlib.h` v0.9.41（MIT，附 LICENSE/README）。
- 整卷 PDF 题面生成 `generator/build_statement_pdf.py`（官方风格封面 / 注意事项 / 页眉页脚 / 样例行号）。
- Lemon 评测机比赛数据导出 `generator/export_lemon.py`（`<比赛>.cdf` + data + source/std 选手，
  支持 `--contest-title` / `--cdf-name`）。
- 完整样例平铺打包 `generator/package_samples.py`（`1/2/3.in/.out`，无子目录 / 无 readme）。
- 盲审新增检查：`不再`（时间/变化措辞）与 `（括号内部表述）`（problem 模式）。

## Changed

- npm 包名由 `dsh-oi-workbench` 改为 **`@muyangplus/dsh-oi-workbench`**，版本升至 **0.1.4**；
  `cordis.patch.yml` 与 README 安装命令同步改为 scoped 包名。
- `export_lemon.py` 默认生成 LemonLime `.cdf`；目标已有 `.cdf` 时默认保留（`--force-cdf` 覆盖）。
- `blind_review.py` 修复 `--release` 裸调用（`const=True` + 默认仓库根）。

## Fixed

- `build_statement_pdf.py`：封面信息表由硬编码 4 题改为动态列数；workdir 相对路径导致的
  XeLaTeX 找不到 tex 问题。
- 交互题本地评测：Windows 管道读改用 `os.read`，避免 `BufferedReader.read` 阻塞到 EOF 造成死锁。
- `story_continuity.py`：轻量 YAML 解析支持行内注释与标量引号。

## 验证（本机）

- `blind_review.py --release`：0 问题 0 提示；
- 本地评测：普通题 / testlib SPJ / 交互题均 100/100 AC；
- `build_contest.py` 全流程（样例 + PDF + Lemon + Hydro/HOJ）在临时目录跑通；
- `story_card.py` / `story_continuity.py` 正向与负例均符合预期。
