# v0.2.0 — 正式版：多轮出题经验、题面硬约束、DSH 原生管理面板

> 聚合 0.1.5 之后的全部迭代（多轮实战出题经验 + 题面书写硬约束 + 插件管理面板）。
> 发布通道：public `dev` 出 npm beta `0.2.0-beta.*`，PR `dev → main` 后由 `release.yml`
> 自动发布 npm 正式版 `0.2.0` 并创建 GitHub Release 与 tag `v0.2.0`。

## Added

- `generator/check_statement_style.py`：题面风格硬约束检查器。扫描 `problem.md` 中的
  全角括号 `（）`、破折号 `——`、答案提示（`答案必为/恒为/不超过/只需输出` 等）与半角括号中文说明，
  支持单题与 `--vol` 整卷批量检查，ERROR 必须为 0。
- `docs/dsh-ui-management.md`：DSH 原生管理面板说明，配套客户端入口与设置页。

## Changed

- 题面硬约束（用户口径）：题面正文禁用 `（）` 与 `——`，禁用答案提示，特殊性质只描述输入形态；
  `SKILL.md`、`specs/statement-style.md`（新增 2.1）、`templates/statement.md`、`docs/lessons-learned.md`（新增第 0 节）同步更新。
- `generator/build_statement_pdf.py`：整卷 PDF 题名头去掉 `题名（pid）`，`注意事项` 标题与注意事项正文模板去括号。
- 多轮出题经验回灌：`generator/build_hoj_package.py`、`generator/build_package.py`、
  `generator/export_lemon.py`、`generator/local_judge.py`、`generator/package_samples.py`、
  `generator/tools/check_problem.py` 按实战修正。
- `hoj-bridge/`：`hoj_api.py`、`publish_problem.py`、`README.md` 按多轮发布实战更新。
- `package.json`：新增 `types`、`exports["./client"]`、`dsh.client` 客户端入口与 `ui-panel` 关键词，
  补齐 `peerDependencies`；`cordis.patch.yml` 注册插件本体与客户端设置页。
- 版本号升至 **0.2.0**（聚合 0.1.1–0.1.6）。

## Fixed

- 题面中残留的解释性全角括号与破折号、以及"此时答案必为 …""答案不超过 …"这类答案提示。
- 整卷 PDF 的题名头与注意事项模板中的括号。

## 验证（本机）

- `generator/blind_review.py --release`：0 问题；
- 新增 `check_statement_style.py` 对样例卷实测：ERROR 0 处、WARN 0 处；
- `python -m py_compile`：全部新增/修改脚本通过；
- 插件构建：`bash scripts/build.sh` 产出 `lib/index.js`、`lib/client.js` 与 `lib/types/**`。
