# v0.1.1 — 批次 1：用户自定义知识库 / 参考题（增删改查）

> 迭代号版本（dev 迭代期，不发布）。对应 `ROADMAP.md` 批次 1。

## Added

- `ui/user_content.py`：用户自定义知识库 / 参考题的增删改查 CLI（仅 Python 标准库）。
  - 知识库：`kb list|show|search|add|add-file|edit|rm|validate`
  - 参考题：`ref list|show|add|rm|validate`
  - 数据存 `~/.dsh-oi-workbench/kb/` 与 `~/.dsh-oi-workbench/reference/`；`--home` 可覆盖（便于测试）。
  - 层级目录映射：入门级→`level-1-basic` / 提高级→`level-2-intermediate` /
    专家级→`level-3-expert`；自定义层级→ASCII slug。
- `templates/kb-card.md`：用户知识库速查卡片模板（frontmatter 字段说明）。
- `specs/user-content.md`：用户自定义内容规范（布局、合并规则、校验、安全边界）。
- `commands/kb.md`：`/oiwb kb` 与 `/oiwb ref` 命令参考。
- `commands/register/oiwb.md`：注册 `/oiwb kb ...`、`/oiwb ref ...` 子命令。

## Changed

- `SKILL.md`：第 1 步「锁定知识点」先并入用户层知识库，同名 `topic` 以用户卡为准；
- `knowledge-base/workflow.md`：新增「用户层知识库合并」一节；
- `README.md`（dev）：新增「用户自定义知识库 / 参考题」一节；内容树与斜杠命令表同步。

## Fixed

- `user_content.py` 初版 `validate_ref_dir` 用带扩展名的文件名求 in/out 交集（`1.in` ∩ `1.out` = ∅），
  导致「无匹配测试点对」误报；改为按去扩展名的 stem 配对。

## 验证（本机冒烟）

- `kb add / list / show / search / edit / add-file / validate` 全绿；
  重复 add 拒绝（exit 1）；缺 `summary` 的坏卡被 `validate` 拦截（exit 1）；
- `ref validate / add / list / show / rm` 全绿；重复 add 拒绝（exit 1）；
- 数据源：内置 `reference/entry/max-number` 复制进用户层并校验通过；
- 双层检索：`kb search 并查集` 同时命中用户卡与内置 `level-2-intermediate.md`。
